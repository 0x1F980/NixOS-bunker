# bunker-panic-tui

☢ Panic button for **panic-flagged deniable zone-VMs**.
Launcher: **panic · service** (`bunker-panic-ui`) — nuclear icon.

Flow: warning → panic code → `bunker-panic` (shred keys/state, lock layers, `sdmem`).

Default code: `changeme` (change `/etc/bunker/panic.conf`).
Does not wipe public decoy zones or host LUKS.

Docs: [docs/deniable.md](../../docs/deniable.md).
