# bunker-broker-tui

Ratatui UI for **net + USB 1→many defaults** in `config/zones.json`.
Host launcher: **defaults · service** (`bunker-broker`).

## Keys

| Key | Action |
| --- | --- |
| `1` | Net / egress defaults screen |
| `2` | USB defaults screen |
| `n` | Start netVM |
| `u` | Start usbVM |
| `w` | Write `zones.json` |
| `j`/`k` or arrows | Navigate list |
| Enter / Space | Cycle net backend (on net screen) |
| `a` / `d` | Add / delete USB vid:pid (usb screen) |
| `?` | Help |
| `q` / Esc | Quit / back |

See also: [docs/usb.md](../../docs/usb.md), [docs/egress.md](../../docs/egress.md).
