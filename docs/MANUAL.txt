NixOS-bunker — host operator manual
===================================

MODEL
  Zone = VM. kind = appvm|disposable|template
  color = host icon + zone terminal. internet = nym|i2p|tor|none
  invisible+layer. panic = keep|lock|wipe. ISO = template=iso + iso=/path
  Brokers: net (1→many) usb (1→many). UI: bunker (ratatui)

COMMANDS
  bunker
    a add · d del · r rename · c color · t type · n net · i hide
    o iso path · Space panic · p ARM · w save · q quit
  bunker-zone …                 # same CRUD via CLI
  bunker-zone-start <zone|all>
  bunker-sflc unlock-zone / unlock|lock <layer>
  bunker-panic / bunker-term / bunker-usb-* / bunker-clip / bunker-wipe

SoT: config/zones.json  then  nixos-rebuild switch --flake .#host
Host: disk/analyse tools only (no mat2). mat2 lives in browser template.
