NixOS-bunker — host operator manual (plain text)
================================================

Also:  man bunker

WHAT THIS IS
  Hardened NixOS host + microVM zones (AppVM / Disposable / Template).
  Brokers: netVM (egress), usbVM (USB 1→many). Not Qubes — contain compromise.

HOST (GNOME) MAY HAVE
  Terminal, Settings, qube launchers (AppVMs/Disposables/Templates/Service),
  bunker-* tools, and emergency disk/backup apps for when VMs are down.
  No daily browser/mail on host.

ZONES
  Source of truth: config/zones.json  (CRUD: bunker-zone …)
  Templates:       templates/*.nix    (bunker-template-edit / Templates folder)

COMMANDS
  bunker-zones                       # ratatui zone CRUD (preferred UX)
  bunker-deniable                    # hide/show whole VMs (Shufflecake layers)
  bunker-panic-ui                    # ☢ panic — wipe panic-flagged deniable keys
  bunker-zone list|add|set|rm|apps|usb|templates|colors
  bunker-broker                      # ratatui net/usb defaults
  bunker-voice                       # ratatui mic anonymizer 1→many (Chimera/anon)
  bunker-zone-start <zone|all>
  bunker-term <zone>                 # colored SSH (also: net, usb)
  bunker-clip send <zone>            # host→zone; host clip KEPT; zone TTL clear
  bunker-clip copy <a> <b>           # zone→zone mediated
  bunker-clip clear
  bunker-usb-attach|detach <zone> <vid:pid>
  bunker-killswitch enable|disable|status
  bunker-wipe <zone>
  bunker-test-isolation [--live]
  bunker-first-boot | bunker-update

ZONE CRUD POLICY
  Preferred:  zones · service  /  bunker-zones  /  bunker-zone CLI
  Hidden VMs: deniable · service  /  docs/deniable.md
  Panic:      panic · service (default code changeme — change PANIC_HASH)
  OK:         hand-edit config/zones.json (same SoT), then nixos-rebuild
  Avoid:      hand-editing Nix modules just to add/remove/tune a zone

CLIPBOARD TTL
  Default 30s for ZONE clipboard after send/copy.
  Hack: /etc/bunker/clipboard.conf  or  BUNKER_CLIP_TTL=60

EMERGENCY (locked out of VMs) — use as admin/sudo when destructive
  GUI:  Disks (gnome-disks), GParted, Files (nautilus), Disk Usage (baobab),
        Text Editor, Logs
  CLI:  cryptsetup, parted, smartctl, nvme, ddrescue, testdisk/photorec,
        rsync, borg, lvm, mkfs.*, mount

LOGIN RECOVERY
  See docs/ADMIN-RECOVER.md in the checkout (boot older generation if needed).
