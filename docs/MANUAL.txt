NixOS-bunker — short cheat sheet (see docs/USER-GUIDE.md)
========================================================

MODEL
  Host clearnet LOCKED. Work in zones. netVM = SOCKS only (1→many). usbVM = USB (1→many).
  kind=appvm|disposable|template  net=nym|i2p|tor|none
  color · invisible+Shufflecake · panic keep|lock|wipe · ISO

TUI (bunker) — primary UI for non-experts
  s start (net|usb|all|zone)   v usb vid:pid   h host-net   b sflc-boot
  a add  d del  r rename  c color  t type  n net  i hide
  u unlock  o iso  f file  Space panic  p ARM  w save  q quit

ALSO CLI (optional)
  bunker-zone-start · bunker-host-net · bunker-sflc · bunker-file · bunker-usb-*

REBUILD
  TUI h→a  then  nixos-rebuild switch --flake .#host-x86_64-linux  then  h→l
